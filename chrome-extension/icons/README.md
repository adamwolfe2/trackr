# Trackr Lens Icons

The manifest.json references PNG icons. The SVG files here are placeholders.

Replace these with real PNG icons before publishing:

- `icon16.png` — 16x16 pixels (toolbar icon)
- `icon48.png` — 48x48 pixels (extensions page)
- `icon128.png` — 128x128 pixels (Chrome Web Store)

Design: White "T" on black (#000000) square, no border-radius. Match the Offset Brutalist style.

You can convert the SVGs to PNGs using any image editor or:

```bash
# Using ImageMagick
convert icon16.svg icon16.png
convert icon48.svg icon48.png
convert icon128.svg icon128.png
```
