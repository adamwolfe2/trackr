## Post 19 — The three-question renewal audit
**Type:** framework
**Best day:** Tuesday

Before you renew any SaaS tool, answer three questions honestly:

1. What problem was this tool bought to solve — and is that problem still real?

If the problem changed or was solved a different way, the tool may be a zombie.

2. Is this tool used by the people it was bought for, at the frequency it was bought for?

Usage data is available for most tools. Pull it. You'll be surprised.

3. If you were evaluating this tool fresh today against current alternatives, would you still pick it?

The market moves fast. A tool that was best-in-class 18 months ago may have been lapped.

If you can't answer yes to all three, you're renewing on inertia — not on merit.

Run this audit 90 days before every renewal. Not 3 days before.
